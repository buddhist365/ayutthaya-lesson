สำหรับครู

แผนการสอน เฉลย ใบงาน เกณฑ์ให้คะแนน และบล็อกพร้อมระบบหลังบ้าน

เครื่องมือที่ใช้พัฒนา

  • HTML, CSS และ JavaScript (ออกแบบให้ใช้ได้ทั้งคอมพิวเตอร์และมือถือ)
  • GitHub สำหรับเก็บไฟล์ และ Netlify สำหรับเผยแพร่เว็บไซต์
  • Decap CMS สำหรับระบบหลังบ้านของบล็อก
  • Google Forms และ Google Sheets สำหรับเก็บคะแนน
